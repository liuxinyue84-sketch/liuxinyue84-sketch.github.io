## 重建提示词记录（非逐字原文）

以下按用户回顾整理，供报告解释开发过程；如需满足“全部原始 prompt”要求，应从 Trae 历史记录导出原文并替换/补充。

### P0-01 初始构建指令（由首轮需求回顾重建）

> 请把现有个人网站改造成英文个人作品集 “Aria’s Sky Journal”。保留淡蓝水彩天空、白云与远山背景、低饱和蓝白色、毛玻璃卡片与胶囊导航。包含 Home、Highlights、Projects、Life、Guestbook 等板块。导航附近放置可手动播放/暂停的舒曼《梦幻曲》音乐按钮并标注英文曲名。Highlights 展示个人简介、教育经历、学术成果和专业技能；本科与硕士信息分开展示。Projects 展示项目经历，移除“管理决策优化建模”项目。Life 展示个人生活与兴趣内容。Guestbook 提供访客留言。全站使用英文，保留温柔手绘旅行日记视觉，增加轻柔交互动画并适配桌面端；移除独立 Music Corner，将自我介绍放入页面内容/页尾。不要加入无关素材或未经提供的个人信息。

### P0-02 网站无法打开时的修复指令（回顾重建）

> 检查本地预览无法打开的原因。恢复本地静态服务器并确认网站可通过本机浏览器访问；不要改动网站内容，除非排查发现必要修复。

### P0-03 Highlights 精简与照片分配（回顾重建）

> 精简 Highlights：移除子导航和与 Projects 重复的 Publication 卡片；学校信息默认收起，访客点击学校卡片后再查看本科成绩/奖项或硕士课程信息。将前三张照片放在首页轮播，其余照片放入 Life / Beyond the Lab 相册。保留其他页面和原有风格。

### P0-04 加入课程笔记检索入口（回顾重建）

> 在 Highlights 底部加入一个课程笔记知识库入口，使用 5205、5434、5583、5584 的课堂笔记作为检索素材。用一句简短英文引导访客提问，保持原布局与视觉，不要把整个页面改成聊天机器人。

### P0-05 将知识库改为可交互 RAG 聊天（回顾重建）

> 将课程笔记检索入口改成可交互聊天窗口：用户输入问题后，从本地 Markdown 课程笔记检索相关内容，回答展示检索到的原文片段和课程/章节来源；加入建议问题。保留静态前端实现，不依赖后端服务，不要虚构笔记中没有的结论；检索不到时清楚说明。保持原页面视觉。

### P0-06 Life 视频、禁用上传与清空旧留言（回顾重建）

> 把提供的两段视频加入 Life 相册，作为可点击预览的媒体项目；移除前端上传照片和视频的功能；清除 Guestbook 旧留言记录。保持其他功能和现有风格，并告知项目源码所在位置。

### P0-07 根据本轮诊断修复本地 file:// 下 RAG（由当前对话记录重建）

> 修复 V0 在直接双击 `index.html` 时 RAG 不能加载笔记的问题。检查浏览器对 `file://` 下 fetch 本地 Markdown 的限制，采用静态可部署的方案把笔记语料随网页打包，同时保留可读 Markdown 文件和 HTTP 部署能力。验证首页/聊天界面、课程笔记检索及来源显示。不要改成后端服务，也不要伪称由 LLM 生成答案。
