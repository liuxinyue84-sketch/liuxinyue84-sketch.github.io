# Few-Shot Demonstrations — Life Media Wall and Marginalia (Iteration 4)

These examples abstract component and interaction patterns from the previously reviewed references. They do not reproduce reference-site copy, identity, or media.

## 1. Asymmetric media wall with keyboard-accessible viewing

- **Input pattern:** A photography portfolio uses an uneven, image-first gallery and an accessible viewing interaction.
- **Output pattern:** Use a deliberately varied, responsive composition; make every media tile a semantic button with an accessible name; preserve a single preview dialog and provide keyboard open/close behavior.
- **Applied to V1:** The existing seven photographs and two videos are rendered in a staggered scrapbook wall. Existing captions and video controls are retained. Enter opens the preview and Escape closes it; automated checks verify both.
- **Source pattern:** `Photography Wall` reference noted in `reference_patterns.md`; no reference assets or content were copied.

## 2. Hand-drawn SVG annotations as restrained page marginalia

- **Input pattern:** A scrapbook portfolio uses original line-art doodles and brief notes to make a page feel personal without expanding the main content blocks.
- **Output pattern:** Add small, low-contrast inline SVGs near an existing section heading or media area; hide purely decorative drawings from assistive technology; preserve the page's existing art direction.
- **Applied to V1:** Two original inline SVG line drawings (a botanical sprig and a small flight-path flourish) sit beside the Life heading and above the media wall. They use muted sage tones and do not overlap readable content.
- **Source pattern:** `Scrapbook Portfolio` reference noted in `reference_patterns.md`; no reference SVG or text was copied.

## 3. Preserve the owner's source material

- **Input pattern:** An image-led portfolio uses category thumbnails and direct media previews.
- **Output pattern:** Reorganize existing owner-supplied images without substituting unrelated stock photography; retain captions and preview behavior.
- **Applied to V1:** The same seven photos and two short films remain in the gallery, with existing labels and modal/video controls. No new personal image or text was introduced.
- **Source pattern:** Art portfolio and photography-wall patterns previously recorded in `reference_patterns.md`.
