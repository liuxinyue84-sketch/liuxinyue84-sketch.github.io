# V2-RAG Knowledge Base Manifest

The browser corpus at `website/rag-knowledge.js` is generated by `scripts/build_knowledge_base.py` from frozen V0 materials. Each record contains an ID, topic title, section path, original Markdown paragraph, and source metadata. Source paragraphs are retained in full; the retrieval layer filters non-informative image-only/very short records without deleting them from the corpus.

- 8 lecture-note Markdown files in `website/knowledge/`
- 9,811 paragraph records from the lecture notes
- 20 supplemental records from four project profiles in frozen V0 `projects.js`
- **9,831 total records** across 9 distinct source files
- The research-paper profile carries the DOI `https://doi.org/10.3390/fi17080353`; its descriptive text is inherited from V0 `projects.js`.

The full serialized JavaScript knowledge object is the canonical corpus archive. `query_runs_v2.json` records the passages actually retrieved for every test query, their BM25 scores, assembled prompts, and displayed answers. Rebuild with:

```sh
python3 scripts/build_knowledge_base.py
```

The source notes and project records are preserved unchanged in the V2 website copy. V0 itself was not modified; hashes captured before work are recorded in `v0_baseline_sha256.txt`.
